# Bunker 01

Небольшой шутер от первого лица в духе Doom. В бункере пять монстров. На каждого нужно два попадания. Уничтожьте всех, чтобы пройти уровень.

## Запуск

```sh
python3 doom.py
```

Нужен Python 3 со стандартным модулем `tkinter`. Все стены, монстры и оружие рисуются программно. Пакеты через pip и файлы с графикой не нужны.

## Управление

| Клавиша | Действие |
| --- | --- |
| W / ↑, S / ↓ | Вперёд и назад |
| A, D | Шаг влево и вправо |
| ←, → | Поворот |
| Пробел или левый клик | Выстрел |
| R | Начать уровень заново |
| Esc | Выйти |
